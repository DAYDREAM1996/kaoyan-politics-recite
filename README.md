# 考研政治 · 核心背诵神器（2027 核心背诵笔记精编）

基于《2027 考研政治核心背诵笔记》**【一、背诵部分】** 全量提取与结构化重构的本地/静态 Web 背诵系统，聚焦「死记硬背核心要点、定性词挖空、闪卡主动回忆与两轮打卡」。

---

## 核心功能

- **📖 章节背诵（46 章 · 805 条要点 · 139 张对比表）**
  - 覆盖 **马原、毛中特、习思想、史纲、思修** 五大科目全部背诵部分章节。
  - **三种背诵模式**一键切换：
    - `⬛ 挖空遮挡`：自动遮挡核心定性词与表格答案栏，点击单块揭晓，支持 `Space` 一键切换本章全显/全隐。
    - `❓ 只看题干`：隐藏标准答案，口头默背后再点击核对。
    - `👁️ 沉浸通读`：清晰排版并高亮核心定性词，适合早晚朗读或考前快速过书。
  - 支持每章 **「第 1 轮 / 第 2 轮」背诵打卡** 与单条 **`🔥 生疏` / `★ 重点`** 标记。
- **📇 卡片抽背（526 张章节背诵卡 + 38 张高频定性词）**
  - 支持按科目、单章或「专攻生疏本」抽背，提供「不会 / 模糊 / 熟练」三档记忆反馈与快捷键（`Space` 翻面、`1/←` 不会、`2/↓` 模糊、`3/→` 熟练）。
- **📊 进度与生疏本**
  - 46 章两轮背诵完成度矩阵、生疏条目汇总，支持一键导出/导入 `localStorage` 进度 JSON 备份。
- **🔍 检索 & 万能原理**
  - 全书 805 条背诵原文实时关键词检索（可定位回原章节）+ 6 大马原分析题万能原理模板。
- **⚡ 避坑自测（辅助）**
  - 保留 418 道理解部分常见命题陷阱正误判断自测。

## 目录结构

```text
.
├── index.html                  # 考研政治核心背诵神器（Vue 3 + Tailwind 静态单页）
├── data.js                     # 结构化背诵数据（免跨域离线加载）
├── politics_data.json          # 结构化背诵数据 JSON
├── build_recite_dataset.py     # 基于 pdftotext -layout 的背诵部分解析与 OCR 修复脚本
├── server.py                   # 本地无缓存 HTTP 服务（默认端口 8080）
└── start.sh                    # 一键启动脚本
```

---

## 快速启动

```bash
python3 server.py
# 或 ./start.sh
```
浏览器访问 `http://localhost:8080`（也支持直接双击 `index.html` 离线打开）。

---

## 重新构建背诵数据（可选）

如需从本地 PDF（需自行放置同目录 `2027核心背诵笔记.pdf...`）重新解析生成 `politics_data.json` 与 `data.js`：
```bash
python3 build_recite_dataset.py
```
依赖 `poppler-utils` 中的 `pdftotext`（需支持 `-layout` 参数）。
